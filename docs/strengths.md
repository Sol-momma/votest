# いついく？ の強み・差別化ポイント

## 一行で言うと

> **候補日10件でも、30秒で答えられる。スマホ専用の日程調整。**

ご飯会・飲み会の日程調整を、**スマホ100%・候補日が多いほどラク**という前提でゼロから設計。

| 層 | 状況 |
| --- | --- |
| 幹事 | 候補日が多い飯会・歓送迎会・忘年会の日程をまとめたい人 |
| 参加者 | 通勤電車・片手で素早く投票したい人 |
| LINE 文化圏 | LINEで送り合うのが当たり前の Z世代〜ミレニアル |

## 5つのコア差別化

### 1. ⚡ 候補日が多いほどラクになる UX

> 「30件の候補日も数タップで投票完了」

| シーン | 一般的なサービス | いついく？ |
| --- | --- | --- |
| 候補10件すべて○ | 10タップ | **1タップ**（「全部◯」） |
| 連続5日間が× | 5タップ | **2タップ**（範囲モード → ×） |
| 1日だけ△ | 1タップ | 1タップ（個別） |

- **一括投票**（全部◯ / 全部🤔 / 全部×）
- **範囲投票**（始点→終点→マーク選択の3ステップ）
- 細かい調整は個別バッジでいつでも可能

→ 「候補日30件のうち、行ける日が1〜5日だけ」という現実のパターンが **数タップで終わる**。

### 2. 📱 スマホ100%最適化

| 要素 | 競合 | いついく？ |
| --- | --- | --- |
| タップターゲット | 小〜中 | **h-12 (48px+)** Apple HIG準拠 |
| 一画面完結 | 横スクロール表 | 縦スクロールのみ |
| safe-area | × | ◯（ホームインジケータ対応） |
| 通勤電車での投票 | つらい | **片手で完結** |

- 全主要CTAが **64-72px高さ**
- viewport `dvh` + `env(safe-area-inset-bottom)`
- 大きい絵文字を意図的にアイコン代わりに使い、視認性UP

### 3. 🔓 ログイン不要・URL一発共有

- アカウント作成・LINE連携・メール認証すべて不要
- URLを送るだけで誰でも投票可能（LINE未利用者にも届く）
- 幹事は管理用 `?admin=token` で締切のみ可

| 競合 | 弱点 |
| --- | --- |
| 調整さん | アカウント無しだが PC UI が前提 |
| LINEスケジュール | LINE 内でしか使えない |
| TimeTreeアレンジ | アプリインストール必須 |

### 4. 📊 出席率順 + 3色スタックバーで一目

- ランキングは **出席率（◯=1, 🤔=0.5, ×=0）の平均値**で自動ソート
- 各候補日に **3色スタックバー**：◯/🤔/× の比率を視覚化
- **比較バー**：1位を基準に他の候補がどれだけ離れているかが直感的
- **🏆 1位バッジ + 漢数字ランク** で勝者感

→ 「数字を頭で計算する手間」がゼロ。結果画面を見せるだけで合意形成完了。

### 5. 🤔 「微妙」を投票できる3段階

- ◯（OK）・🤔（微妙）・×（NG） の **3段階**
- 「行けるかもしれないけど断言できない」という現実の感情を1タップで共有
- 集計でも `0.5` ポイントとして反映されるので **頭数より正確**

→ 単純な ◯× だと「条件付きOK」を備考欄に書く手間が発生。3段階で会話が要らない。

## 設計哲学

### 「決められた人が偉い」のではなく「決まる過程をラクにする」

幹事業務の核心は **意思決定** ではなく **集計と提案**。いついく？ は集計を完全自動化することで、幹事の負担をゼロに近づけます。

### 「データを入れるアプリ」ではなく「会話を加速するツール」

ユーザーが入力する情報は最小（名前 + 投票のみ）。データベースとしての価値より、**LINEでの会話に貼られた瞬間に意思決定が始まる**ことを最優先。

### モバイル → デスクトップ の順で設計

ほとんどの利用シーンがスマホ。デスクトップは「幹事が PC で複数イベントを管理したい場面」のみと想定し、レスポンシブで段階的に余白を活かす。

## 想定する使用シーン

1. **🍰 卒業式週間のご飯会**
   - 候補日が10〜15日と多い → 範囲投票でサクッと
2. **🍣 忘年会**
   - 12月の平日・週末候補が広い → 一括◯ベース + 仕事日だけ×
3. **🌸 歓送迎会**
   - 主賓1名 + 参加者多数 → 主賓の都合を見ながら投票
4. **🎂 サプライズ誕生日会**
   - 全員の都合確認を本人にバレずに → URLを「他用件」と言って送る
